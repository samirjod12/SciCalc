SciCalc - scientific calculator for Windows

RUN WITHOUT BUILDING:  python scicalc.py
BUILD THE .EXE:        double-click build_exe.bat  ->  dist\SciCalc.exe
(Needs Python 3.9+ from python.org, with "tcl/tk" ticked - it is by default.)

Keep scicalc.py and scicalc_engine.py in the same folder.

Features: natural results (fractions, root, pi forms), S<->D toggle, DEG/RAD/GRA,
sin/cos/tan + inverses, log, ln, powers/roots, factorial, nCr/nPr, integral,
derivative, Ans, memory (M+/M-), history, copy/paste, resizable window,
larger/smaller text (Ctrl +/-), always-on-top.
Keyboard: type normally, Enter = calculate, Esc = clear, Up/Down = previous entries.
